ÖMRÜM KADRİNİ BİLMEDİM

Ömrüm bana emanetim
Armağan sana ziyan ettim
Seni şer yolda sarfettim
Ömrüm kadrini bilmedim.

Göz verdi hakkı görmedim
Hak yolu doğru sürmedim
Ganî ya medet demedim
Ömrüm kadrini bilmedim.

Dünyanın hak sedasını
Almadım aşk gıdasını
Kul sevgisi hüdasını
Ömrüm kadrini bilmedim.

Muhammed'e yanaşmadım
Tanrımın ulaşmadım
Şefaate kavuşmadım
Ömrüm kadrini bilmedim.

Baştan başa kusur oldum
Ben nefsime esir oldum
Defterde günahla doldum
Ömrüm kadrini bilmedim.

Aldandım fani dünyaya
Çalışmadım hiç ukbaya
Varamadım cennet Tubaya
Ömrüm kadrini bilmedim.

Zikrullahı dil vermedim
Aşkulallah yol vermedim
Ben bu hale akıl ermedim
Ömrüm kadrini bilmedim.

Dervişan bir hallerim var
Şer konuşan dillerim var
İsyan esen yellerim var
Ömrüm kadrini bilmedim.

Usanmadım isyandan
Rahmetmezse hak yaradan
Nola orda bu tatlı can
Ömrüm kadrini bilmedim.

Helal haram ayırmadım
Hakka doğru yol sormadım
Ömrüme delil almadım
Ömrüm kadrini bilmedim

Kılamadım beş vaktimi
Bozdurdum bu ahdimi
Günlere verdim vaktimi
Ömrüm kadrini bilmedim.

Dergahında el açmadım
Nefsi haramdan geçmedim
Hak Yolunu ben seçmedim
Ömrüm kadrini bilmedim.

Sana ayan halim hüdam
Sen eyle kalbime ilham
Muhammede selat selam
Ömrüm kadrini bilmedim.

Mevladan oldu hidayet
Muhammed'ten bir şefaat
Evliyadan oldu himmet
Ömrüm kadrini bilmedim.

Sana ayan halim mevla
Bunca isyan kıldım sana
Şimdi pişman oldum amma
Ömrüm kadrini bilmedim.

Benim halim böyle dilde
Zarımı duyun bülbülde
Pişmanlığım var gönülde
Ömrüm kadrini bilmedim.

Bünyamin'em payın alın
Sabır Köşesinde kalın
Yaradana kulluk kılın
Ömrüm kadrini bilmedim.
